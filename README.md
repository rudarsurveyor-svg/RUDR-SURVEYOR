# RUDR SURVEYOR

Land measurement and surveying utility app for Android/iOS.

## Included
- Gujarati + English UI
- RUDR SURVEYOR logo
- App Icon + Splash configuration
- Land Measurement
- Area Calculator
- Unit Converter
- Surveyor Knowledge / Information
- Survey Report
- Customer Care: 8487847474

## Build locally
```bash
flutter pub get
dart run flutter_launcher_icons
dart run flutter_native_splash:create
flutter run
```

## Codemagic
The repository includes `codemagic.yaml` with Android debug/release workflows.
Connect the GitHub repository to Codemagic and start the `android-release` workflow.
